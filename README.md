# Harshit Kumar Portfolio

Personal portfolio website for Harshit Kumar, a frontend and WordPress developer.

The site presents selected professional work.It also includes a resume page.

Live site: [harshitkumar.tech](https://harshitkumar.tech)

## Features

- Responsive layout for desktop, tablet, and mobile
- Light and dark theme switcher with saved preference
- Selected professional work presented at a capability level
- Resume page
- Contact section with email, LinkedIn, and GitHub links
- Semantic HTML and SEO metadata
- Sitemap, robots.txt, and structured data
- No build step or framework required

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- GSAP for page animation

## Project structure

```text
index.html                 Home page
style.css                  Shared styles
script.js                  Theme switcher and interactions
favicon.svg                Browser favicon
robots.txt                 Search crawler rules
sitemap.xml                Public page URLs
resume/index.html          Resume page
```

## Run locally

Open `index.html` directly in a browser, or run a local static server from the project folder:

```powershell
py -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

## Deployment

The site is a static website and hosted on GitHub and Vercel. The production domain is `harshitkumar.tech`.

For Vercel, import the GitHub repository and deploy it without a build command. Add the custom domain in the project settings after deployment.
